# Risk Register (Template)

Maintain a simple, living risk register for every project.

| ID | Description | Impact (High/Med/Low) | Likelihood (High/Med/Low) | Owner | Mitigation | Status |
|----|-------------|-----------------------:|---------------------------:|-------|-----------|--------|
| R-001 | Example: Third-party API rate limit may block production traffic | High | Med | Developer Team | Implement retry/backoff and caching; contact vendor | Open |

Guidance:
- Review and update the register weekly in the PM sync.
- Assign an owner for each risk and capture mitigation steps and triggers for escalation.
- Use the "Status" column to indicate Open / Monitoring / Mitigated / Closed.
